# БыстроПит

Учебное веб-приложение на Python и FastAPI. Касса публикует заказ в RabbitMQ и сразу возвращает его номер. Фоновый обработчик забирает сообщение, имитирует работу кухни и отмечает заказ готовым. Табло показывает эти изменения автоматически.

## Запуск

Понадобятся Python и Docker для локального RabbitMQ. В PowerShell из каталога проекта выполните:

```powershell
docker compose up -d
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn main:app
```

Откройте [кассу](http://127.0.0.1:8000) или [документацию API](http://127.0.0.1:8000/docs). Локальный брокер из Compose слушает порт 5673. Для подключения к существующему брокеру задайте его AMQP-адрес в переменной окружения `RABBITMQ_URL` перед запуском Uvicorn.

## Сценарий демонстрации

1. Нажмите **Пауза кухни** на табло.
2. Добавьте блюда в корзину и отправьте один или несколько заказов. Касса вернёт номера, а заказы появятся в колонке **В очереди**.
3. Нажмите **Запустить кухню**. Обработчик забирает по одному заказу. Текущий заказ появится в колонке **Готовятся**, а через несколько секунд переместится в **Готовы**.

В [панели RabbitMQ](http://127.0.0.1:15673) можно открыть очередь `bystropit.orders.*` и сравнить число ожидающих сообщений с табло на паузе. Для локального брокера логин и пароль — `guest`.

Табло общее для всех вкладок одного экземпляра приложения. История заказов хранится в памяти и сбрасывается при перезапуске. Запускайте один процесс Uvicorn. Для остановки нажмите Ctrl+C и выполните `docker compose stop`.

## Изображения

Фотографии в `static/media` созданы встроенным ImageGen. Для баннера использован промпт с чизбургером, картофелем и стаканом в тёмно-зелёном интерьере. Для меню каждый из этих предметов снят отдельно на светлом фоне.
